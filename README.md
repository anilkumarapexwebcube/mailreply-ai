# MailReply AI

MailReply AI is an AI reply assistant inside Gmail. It reads the Gmail thread you are looking at, drafts the reply in your voice, and puts it straight in the composer.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
